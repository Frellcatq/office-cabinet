# Рабочий кабинет · Северная линия

Приложение координатора проектов на Python + Streamlit. Минимальная завершённая
версия: загрузка плана, задачи со сменой статуса, календарь недель, материалы,
три показателя обзора, выгрузка CSV и резервная копия ZIP.

## Запуск

```bash
./run.sh        # создаст .venv при первом запуске и откроет http://localhost:8501
```

Ручной вариант:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py --server.port 8501
```

Первое открытие — пустой кабинет. Порядок работы:

1. «Задачи» → «Загрузить исходный план (XLSX)»: книга с листами «Задачи»,
   «Встречи», «Проекты», «Сотрудники». Данные проверяются и заменяют набор.
2. «Материалы» → загрузка DOCX/TXT (до 5 МБ на файл, 20 МБ всего) с привязкой
   к проекту.
3. «Отчёты» → выгрузка выборки задач в CSV (UTF-8 BOM, разделитель «;»).
4. «Резервная копия» → скачать ZIP перед выходом; загрузить при следующем
   посещении. Автосохранения между посещениями нет.

## Публикация

Для публикации подходят только эти файлы и каталоги:

- `app.py`
- `cabinet/` (код приложения)
- `requirements.txt`
- `README.md`

Не публикуются (уже в `.gitignore`): `data_input/`, `design_reference/`,
`exports/`, `backups/`, `.venv/`, секреты и пользовательские архивы. Приложение
не читает исходные материалы автоматически и не хранит данные между сеансами:
каждое открытие — пустой кабинет до загрузки плана или резервной копии.

Простой вариант публикации — Streamlit Community Cloud: репозиторий с файлами
выше, main file `app.py`, требования подтянутся из `requirements.txt`.
